# Simple Interest Calculator

A small Bash project that calculates **simple interest** from user input: principal, rate of interest, and time period.

## Formula

```
Simple Interest = (Principal x Rate x Time) / 100
```

- **Principal** – the initial amount of money
- **Rate** – annual rate of interest (in %)
- **Time** – time period in years

## Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

Example session:

```
Enter the principal amount: 10000
Enter the rate of interest (% per year): 5
Enter the time period (in years): 2
Simple Interest = 1000.00
Total Amount    = 11000.00
```
